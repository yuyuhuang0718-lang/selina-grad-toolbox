S01S06

樞紐分析表是什麼？

不用改變原始資料，就把多筆明細整理成不同角度的摘要。

  • 樞紐分析表用於比較和彙總，不是把原始資料刪掉或重新排序。
  • 同一份來源資料可以從「課程」、「地區」、「日期」等不同角度切換檢視。

S01S02

先整理適合分析的原始資料

一列代表一筆紀錄，一欄代表一個欄位。

  • 維持單列、唯一且不為空的欄名；避免合併儲存格及空白分隔列。
  • 每欄盡量維持一致資料型別；人數應為數值而非附有「人」文字的字串。
  • 建議將資料轉成 Excel 表格，新增資料列更容易被來源範圍涵蓋；仍需視設定重新整理。

S01

四個欄位區域

將欄位放到列、欄、值或篩選，決定如何整理摘要。

  • 列（Rows）：指定每一列代表什麼，例如課程主題。
  • 欄（Columns）：用來左右比較，例如北區／南區。
  • 值（Values）：放需要加總或計數的資料，例如報名人數。
  • 篩選（Filters）：限制目前分析的資料範圍。

S01

加總和計數不能混淆

同一欄位的「加總」與「計數」回答不同問題。

  • 加總（Sum）回答全部人數有多少；計數（Count）回答有多少筆非空記錄。
  • 以 6 筆範例資料來看，加總報名人數是 60，但記錄筆數是 6。
  • 若值區域出現計數，先檢查資料是否被 Excel 判讀為文字，再調整彙總方式。

WIKI · slicer
S04

用切片器進行互動篩選

按鈕式篩選讓不同情境的比較更直覺。

  • 切片器不會刪除原始資料，只是更改目前展示的資料。
  • 本教學使用「全部／北區／南區」模擬切片器概念。
  • 同一切片器連接多個樞紐分析表時，這些樞紐分析表需要共用相同資料來源。

S02S03

新增資料後記得更新

來源資料與樞紐分析結果之間需要確認同步。

  • 新增紀錄後先確認樞紐分析表的來源範圍有涵蓋該資料。
  • 接著執行重新整理；不要假設每個 Excel 版本都會即時自動更新。
  • 若來源欄位結構大幅改動，應評估重建樞紐分析表。

WIKI · group
S05

把日期整理成月份與季度

群組讓時間序列更容易比較。

  • 若來源有真正的日期型別，可依月份或季度群組。
  • 若資料是文字樣式的日期，可能需要先修正型別。
  • 分組只是分析視角，並不代表原始日期欄位被改寫。

S06S01

用樞紐分析圖讀懂趨勢

將彙總後的值轉為可讀圖表。

  • 先建立或確認樞紐分析結果，再選擇適合比較的圖型。
  • 例如長條圖可比較 Word、Excel、簡報各課程的人數。
  • 圖表應保有標題、單位，避免把彙總筆數誤寫成總人數。

建立樞紐分析表

Create a PivotTable to analyze worksheet data

  • 樞紐分析表能彙總和分析資料，以觀察比較、模式與趨勢。
  • 原始資料採欄為欄位、單列欄名，不宜合併儲存格或雙層標題。
  • Windows 桌面版可選取資料後使用「插入 → 樞紐分析表」。

調整樞紐分析表來源

Change the source data for a PivotTable

  • 已建立的樞紐分析表可以修改來源範圍，納入新資料列。
  • 若資料欄位數量有大幅變更，官方建議考慮建立新的樞紐分析表。
  • 在 Windows 桌面版可透過分析索引標籤中的「變更資料來源」調整。

重新整理資料

Refresh PivotTable data

  • 來源資料更新後，使用重新整理可更新樞紐分析表內容。
  • 可在樞紐分析表中按右鍵選「重新整理」，或使用「全部重新整理」。
  • 自動重新整理的功能會隨 Excel 版本、平台及資料來源而有差異，不能一概保證即時更新。

S04查閱 2026-11-10

交叉分析篩選器

Use slicers to filter data

  • 交叉分析篩選器以可點選的按鈕篩選表格或樞紐分析表。
  • 篩選器會顯示目前選取狀態，便於使用者知道哪些資料被展示。
  • 若要同一個篩選器連接多個樞紐分析表，相關樞紐分析表必須共用相同來源。

群組與時間彙整

Group or ungroup data in a PivotTable

  • 群組功能可將資料分成適合分析的區間。
  • 日期欄位可依月份、季度等時間範圍群組。
  • 在 Windows 桌面版可對樞紐分析表中的值按右鍵，選「群組」設定區間。

樞紐分析圖

Create a PivotChart

  • 樞紐分析圖把彙整的資料呈現為圖像，幫助觀察比較。
  • Windows 桌面版可從「插入 → 樞紐分析圖」建立；不同平台操作可能不同。
  • 對樞紐分析表進行篩選時，其關聯的樞紐分析圖也可反映篩選結果。
